# Pelican Plugins (personal fork)

A personal collection of [Pelican Panel](https://pelican.dev) plugins, forked from the original [pelican/plugins](https://github.com/pelican/plugins) repository and maintained independently going forward.

## Plugins

- [Player Counter](/player-counter) - Show connected players count for game servers, including Velocity/BungeeCord/Waterfall proxy support
- [Minecraft Modrinth](/minecraft-modrinth) - Download, update and automatically keep up to date Minecraft mods & plugins from Modrinth

Both plugins are based on the original work of **Boy132** (and **H1ghSyst3m** for Minecraft Modrinth) from the upstream [pelican/plugins](https://github.com/pelican/plugins) repository, licensed under GPLv3 (see [LICENSE](LICENSE)). This fork is maintained independently and is not affiliated with or endorsed by the original project.
